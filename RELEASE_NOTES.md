# Release Notes — Version 1.0.0

This Supabase edition replaces the localhost Express/MySQL/XAMPP backend with:

- Supabase PostgreSQL
- Supabase Auth
- Row Level Security
- Generated Data API
- Transactional PostgreSQL RPCs
- Supabase Storage
- Protected Edge Functions

The React healthcare dashboard, role-based workflows, patient records, visits, consultations, inventory, issuance, staff management, reports, audit trail, notifications, settings, themes, responsive design, and tasteful 3D login visual are retained.
